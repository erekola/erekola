# Security Policy

This repository holds my GitHub profile README and no code. Each project the README links to has its own repository and its own SECURITY.md, and a report about one of them belongs there.

## Reporting a Vulnerability

If you find a security issue in this repository or on turva.dev, report it privately by emailing **info@turva.dev**. Send encrypted reports to erik@turva.dev. The OpenPGP key is at https://turva.dev/pgp-key.asc.

Please do not open a public issue for security reports.

You can expect an initial response within one business day. If the issue is confirmed, a fix will be prioritized and you will be kept informed of progress.
